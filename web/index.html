空いたところをタップでノート、指でなぞると表示が動きます。ノートは押さえたまま動かし、2 回タップで歌詞。空いたところをクリックでノート（ドラッグで長さ）。ダブルクリック か Enter で歌詞、続けて Enter で次のノートへ。右端のドラッグで長さ、↑↓ で音の高さ、Shift+ドラッグで範囲選択、右クリックか Delete で削除。

1歌わせたい声

話し声の録音をここにドロップ

    5〜10 秒ほど、普段どおりに話した声で十分です。静かな場所で録ると似やすくなります。録音はブラウザの外へ送られません。

    2伴奏なくても可

    伴奏の音声をここにドロップ
    楽譜の 0 拍目は伴奏の 秒
    伴奏の音量−5 dB

    メロディを再生すると伴奏も一緒に鳴ります。ずれていたら秒数を合わせてください。楽譜の上に伴奏の波形が出ます。

    使い方

    左で楽譜を作り、右で声を入れて「歌わせる」を押します。楽譜は MusicXML（MuseScore など）、UTAU（.ust）、OpenUtau（.ustx）、MIDI、VOCALOID（.vsq / .vsqx / .vpr）、Synthesizer V（.svp / .s5p）、CeVIO（.ccs）を開けます（ドロップでも可）。

    ノートを置く空いたところをクリック。そのまま横にドラッグすると長さ
    動かす・伸ばすノートをドラッグ／右端をドラッグ。←→ で前後、Shift+←→ で長さ
    音の高さ↑↓（Shift で 1 オクターブ）。鍵盤をクリックで音を確認
    歌詞ダブルクリックか Enter。Enter で確定して次のノートへ。上の欄からまとめて流し込みも
    伸ばす音歌詞に「ー」と書くと前の母音を伸ばします
    選択Shift+クリックで追加、Shift+ドラッグで範囲、Ctrl+A で全部、Alt+←→ で隣へ
    編集Ctrl+C/V でコピー（再生位置に貼り付け）、Ctrl+D で複製、Ctrl+Z で元に戻す
    再生Space でメロディ。上の目盛りをクリックで再生位置
    表示Ctrl+ホイールで横の拡大縮小

    楽譜はこのブラウザに自動で保存されます。歌詞はひらがなで書いてください（入力したカタカナはひらがなに直します）。
